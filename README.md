## Project 1: RevOps Automation Engine

**Status:** Working Python prototype — Week 2

I'm building a practical revenue operations toolkit to clean, validate, and prepare CRM lead data for downstream workflows.

### What works today
- Read lead data from CSV files using Python.
- Detect missing company names and invalid scores.
- Remove duplicate companies, including differences in capitalisation.
- Classify priority leads using a score threshold.
- Calculate qualification rates based on clean records.
- Export validated leads to `clean_leads.csv`.
- Run a basic assertion to check the validated record count.

### Latest test (synthetic data)
- Input records: 7
- Unique valid leads: 4
- Priority leads: 3
- Clean-lead qualification rate: 75%

**Tools:** Python, CSV, Git, GitHub
